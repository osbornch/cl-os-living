| Metric            | 核心问题           |
| ----------------- | -------------- |
| **Novelty（新鲜）**   | 我今天看到什么新东西？    |
| **Awe（敬畏）**       | 有什么让我觉得世界比自己大？ |
| **Challenge（挑战）** | 我有没有离开舒适区一点点？  |
| **Story（故事）**     | 这件事值得讲给别人听吗？   |
| **Discovery（发现）** | 我发现了什么关于自己？    |
| **Presence（在场）**  | 我有没有真正活在当下？    |
| **Energy（能量）**    | 回来后我是更活还是更空？   |
