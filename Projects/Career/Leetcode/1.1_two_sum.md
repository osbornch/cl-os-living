# Problem

## Two Sum

Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to target.

---

# Scaffolding

## Option 1: Brute Force

### Idea

枚举所有可能组合。

### Code

```python
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        if nums[i] + nums[j] == target:
            return [i, j]
```

### Complexity

```text
TC: O(n²)
SC: O(1)
```

### Bottleneck

```text
重复检查大量 pair
```

---

## Option 2: Two Pass HashMap

### Idea

第一遍建立 value -> index

第二遍寻找 complement

### Complexity

```text
TC: O(n)
SC: O(n)
```

### Tradeoff

```text
需要遍历两次
```

---

## Option 3: One Pass HashMap

### Idea

边遍历边查找。

### Complexity

```text
TC: O(n)
SC: O(n)
```

### Key Question

```text
什么时候放入 hashmap？

Before Check?
After Check?
```

# Iteration Log

## Iteration 1

### Hypothesis

```text
先放入 map
再检查 complement
```

### Code

```python
map = {}

for i, num in enumerate(nums):
    complement = target - num

    map[num] = i

    if complement in map:
        return [i, map[complement]]
```

### Failed Test Case

```python
nums = [3,2,4]
target = 6
```

### Output

```python
[0,0]
```

### Expected

```python
[1,2]
```

### Root Cause

```text
当前元素先进入 map。

当 complement == num 时，
元素会匹配到自己。
```

### Lesson

```text
HashMap 中不应该包含当前元素。
```

---

## Iteration 2

### Hypothesis

```text
增加 index 判断。
```

### Code

```python
map = {}

for i, num in enumerate(nums):

    complement = target - num

    map[num] = i

    if complement in map and map[complement] != i:
        return [i, map[complement]]
```

### Result

```text
通过部分测试。
```

### Root Cause

```text
试图修补症状。

没有解决根本问题：

当前元素仍然被提前放入 map。
```

### Lesson

```text
不要修 Bug。

先找到 Bug 的来源。
```

---

## Iteration 3 (Correct)

### Hypothesis

```text
先检查。

再插入。
```

### Code

```python
map = {}

for i, num in enumerate(nums):

    complement = target - num

    if complement in map:
        return [i, map[complement]]

    map[num] = i
```

### Result

```text
All tests passed.
```

### Why It Works

```text
HashMap 只保存之前遍历过的元素。

不会匹配当前元素自己。

满足题目要求。
```

# Pattern Extraction

## Pattern Name

```text
One Pass HashMap
```

### Core Principle

```text
Check First
Insert Later
```

### Mental Model

当前元素：

```text
我负责寻找搭档
```

HashMap：

```text
保存历史元素
```

流程：

```text
Current Element
       ↓
Check History
       ↓
Found?
       ↓
Yes → Return
No
       ↓
Add To History
```
