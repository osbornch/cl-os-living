| 分析维度                       | 核心问题           |
| -------------------------- | -------------- |
| **结构分析（Structure）**        | 它是怎么组成的？       |
| **风险分析（Risk）**             | 什么可能失败？        |
| **收益分析（Return）**           | 成功后价值有多大？      |
| **成本分析（Cost）**             | 要投入多少时间、金钱、精力？ |
| **机会成本（Opportunity Cost）** | 放弃了什么？         |
| **约束分析（Constraint）**       | 真正限制发展的瓶颈是什么？  |
| **杠杆分析（Leverage）**         | 哪个行动能产生最大的回报？  |
| **敏感性分析（Sensitivity）**     | 哪个变量最重要？       |
| **相关性分析（Correlation）**     | 哪些因素其实绑在一起？    |
| **因果分析（Causality）**        | 真正的原因是什么？      |
| **系统分析（Systems）**          | 各部分如何相互影响？     |
| **反馈分析（Feedback）**         | 有没有正反馈或负反馈？    |
| **时间分析（Time Horizon）**     | 短期和长期是否一致？     |
| **概率分析（Probability）**      | 不同结果发生的可能性？    |
| **情景分析（Scenario）**         | 乐观、中性、悲观分别怎样？  |
| **压力测试（Stress Test）**      | 最坏情况下还能承受吗？    |
| **可逆性分析（Reversibility）**   | 做了还能回头吗？       |
| **可选性分析（Optionality）**     | 是否增加未来选择？      |
| **可扩展性分析（Scalability）**    | 成功后能放大多少倍？     |
| **护城河分析（Moat）**            | 别人为什么难以复制？     |
